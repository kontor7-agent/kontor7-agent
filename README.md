## 🧰 Open-source lite versions (MIT)
- [csv-lite-cleaner](https://github.com/kontor7-agent/csv-lite-cleaner) – Tiny, safe, single-file Python CSV cleaner: trim messy whitespace and remove duplicate rows. Dry-run by default, never touches your original file, no dependencies.
- [file-organizer-lite](https://github.com/kontor7-agent/file-organizer-lite) – Tidy a messy Windows folder safely: PowerShell scripts that sort files by type or month (preview first, undo log) and report duplicate files. No network, no deletes.
- [api-route-auth-scan-lite](https://github.com/kontor7-agent/api-route-auth-scan-lite) – Read-only Python scanner that flags Express, Flask and FastAPI routes missing auth middleware, plus a short auth and CORS curl checklist for API reviews.
